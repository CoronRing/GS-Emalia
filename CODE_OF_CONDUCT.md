# Code of Conduct

## The short version

Be decent. Assume the other person is acting in good faith. Criticise code, not
people. Nobody here owes you their time.

## The standard

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Read it if you want the long form; it applies in full to issues, pull requests,
discussions, commit messages and any other project space.

In practice, the behaviour that gets someone removed is: harassment, personal
attacks, publishing someone's private information, sustained disruption, and
sexualised or discriminatory language or imagery.

## Reporting

If someone's behaviour is a problem, tell the maintainers. Open a private
report through the repository's
[security advisory form](https://github.com/CoronRing/GS-Emalia/security/advisories/new)
— it is the private channel this repository has — or contact
[@CoronRing](https://github.com/CoronRing) directly.

Reports are handled confidentially. You will not be asked to justify being
uncomfortable, and reporting something in good faith will never count against
you.

## Enforcement

Maintainers may edit or remove comments, commits, issues and pull requests that
break this standard, and may ban a contributor temporarily or permanently.
Where a decision is not obvious, maintainers will explain it.

## Scope

This applies in project spaces, and anywhere someone is representing the
project in public.
